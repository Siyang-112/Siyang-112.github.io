BAIC Off-road Vehicle (B41V) HMI

Role:HMI Designer
Company:CapsuleTech
Client:BAIC Group
Duration:2022

Independently designed the interaction for AVM (Around View Monitor), media player, and system settings for BAIC's off-road vehicle platform, with solutions tailored to complex terrain scenarios unique to off-road driving.

Challenge

Off-road vehicles face unique HMI challenges: users need quick access to terrain-relevant information (AVM, incline angle, wading depth) while navigating complex environments. The UI must be glanceable and usable even on rough terrain with vehicle vibration.

Approach

  • Designed AVM with wading view for river crossings and terrain overlay
  • Created media and system settings with large touch targets for rough driving
  • Conducted pre-, mid-, and post-user tests; generated data reports
  • Platformized interactive functions across multiple BAIC models

Results

70%+
User preference in blind test (sample: 50 off-road users)
3
Vehicle models platformized

Key Deliverables

  • AVM interaction design
  • Media player UI
  • System settings architecture
  • User testing reports
  • Interactive specifications
  • Cross-model platform specs
