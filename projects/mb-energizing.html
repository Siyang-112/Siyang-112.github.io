Energizing App In-Car Design

Role:Senior HMI Designer
Company:Mercedes-Benz
Focus:Wellness Experience
Duration:2024 — Present

Designing the in-car Energizing application that orchestrates multiple vehicle systems — seat massage, climate, ambient lighting, fragrance, and audio — into cohesive wellness programs that adapt to the driver's state and context.

Challenge

How to coordinate 5+ vehicle subsystems (seat, HVAC, lighting, fragrance, audio) into a unified wellness experience that feels natural and non-intrusive? The interface must make complex multi-system orchestration feel simple and personal.

Approach

  • Defined wellness program archetypes (Vitality, Comfort, Refresh, Calm)
  • Designed visual language for multi-sensory coordination feedback
  • Created adaptive algorithms that respond to time-of-day, weather, driving duration
  • Built customization flows for users to create personal wellness programs

Key Deliverables

  • Energizing app UI design
  • Wellness program framework
  • Multi-system coordination logic
  • Personalization engine UX
  • Real-time feedback visualization
  • Program creation wizard
