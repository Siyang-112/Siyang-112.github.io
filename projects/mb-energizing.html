Mercedes-Benz 多感官健康体验 HU / RSE / Ultrascreen / RC 2023 — 至今

Energizing 畅心空间

奔驰座舱内的多感官健康程序系统，将视频、音乐、氛围灯、座椅按摩统一编排，围绕用户情绪状态组织成完整的沉浸体验。

座舱如何从交通工具升格为主动调节身心状态的空间？

背景

长途驾驶、等待充电、高压通勤后的放松——这些碎片化场景中，用户需要的不是功能堆叠，而是一个能理解情绪状态并主动提供体验的空间。Energizing 覆盖车机主屏（HU）、后排屏幕（RSE/RSU）、超宽屏（Ultrascreen）、远程控制（RC）及手机端，将多感官元素统一编排为完整的健康程序。

产品定义

情绪驱动的体验选择

系统提供 Energy、Good Vibes、Focus、Relax、Power Nap、Fresh Breeze、Warm & Cosy、Performance（AMG 专属）等多种健康程序，覆盖从激动到睡眠的全情绪曲线。用户不需要理解底层功能逻辑，只选择"现在想要什么感觉"。

核心能力是 Energizing Coach / Vital Sensing。通过连接智能手表和 Healthkit 获取生物数据（心率、压力、睡眠质量），结合车内摄像头面部识别和座椅压力传感器，系统判断驾驶员当前状态，再结合路况和驾驶时长，通过推荐引擎主动匹配程序——从"用户去找功能"变成"功能来找用户"。

多座位协同是另一个关键特性。HU/RSE 多屏多座位支持独立或联动控制——全车乘员各自享受个性化体验，或同步体验同一个 Program。VAN 车型有专门的座位选择逻辑，支持运行中动态增减座位。

设计亮点

Ultrascreen 全屏沉浸

程序运行时支持全屏动画铺满超宽屏，所有 UI 元素消失只剩下内容本身。控制面板通过手势唤出——最大化沉浸感同时保留可控性。视频画面与车内氛围灯色彩实时呼应，屏幕内容和灯光构成统一的色彩场域，车内空间本身成为内容的延伸。

渐进式引导与克制推荐

Vital Sensing 连接流程将手机授权→手表连接→数据获取拆解为清晰步骤化流程（QR code 扫码授权），解决了早期"同一状态加多次 toast 导致用户迷失"的问题。推荐时机做了克制——不弹窗打断，而是在合适的上下文（如连续驾驶两小时后）以 toast 方式非侵入呈现建议。

跨屏一致性

从 HU 到 VAN 后排到 RC 到 Ultrascreen，设计语言和交互模式保持统一，同时根据屏幕尺寸和场景适配布局。运行指示器让用户始终清楚程序状态，多座位冲突有明确规则（同程序合并/不同程序替换 + deactivation toast 通知）。
